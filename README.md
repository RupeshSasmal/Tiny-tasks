# Tiny Tasks - Task Management App

Tiny Tasks is a task management application built with React Native (Expo) and Node.js/Express. The application integrates with Google Calendar to allow tasks and calendar events to be managed together.

## Features

- Create and manage tasks
- Google Calendar integration
- Google OAuth 2.0 authentication
- Synchronization with Google Calendar events
- Mobile application built with React Native and Expo
- Backend API built with Node.js and Express

## Tech Stack

### Frontend

- React Native
- Expo
- JavaScript

### Backend

- Node.js
- Express.js

### APIs and Authentication

- Google Calendar API
- Google APIs
- OAuth 2.0

## Project Structure

- frontend/ - React Native / Expo application
- backend/ - Node.js / Express backend

## Running the Project

### Backend

Install the backend dependencies and start the development server.

Commands:

    cd backend
    npm install
    npm run dev

### Frontend

Install the frontend dependencies.

Commands:

    cd frontend
    npm install

Start the Expo development server.

    npx expo start

For Android development:

    npx expo run:android
